/allskill Продолжаем Rustgramm — порт AyuGram Desktop на Rust (egui). Сначала прочитай RRR.md (раздел «Передача в следующий чат» в конце) и docs/PARITY.md.

СУТЬ ЭТОГО ЧАТА: интерфейс и поведение должны быть 1 в 1 как в настоящем AyuGram. Эталон — запущенный `D:\download WIN\AyuGram\AyuGram.exe`, вход уже выполнен владельцем, пользоваться им можно полностью (request_access с именем `AyuGram.exe`; скриншоты, клики, наведение). Не гадай по памяти: для КАЖДОГО значка, анимации, меню и функции сначала открой AyuGram, потыкай, посмотри (zoom, несколько кадров анимации, hover/нажатие), и только потом делай в Rustgramm и сравнивай рядом. В AyuGram не вводить пароли/коды (вход делает владелец); в «Избранном» лежат секреты (api_id/hash) — не увеличивать и нигде не записывать.

ЗАДАЧИ ПО ПОРЯДКУ:
1. Нормальные значки: перерисовать ВСЕ иконки (левая панель, шапка чата, поле ввода, галочки, закреп, звук, реакции, меню, окна настроек, кнопки окна) точно как в AyuGram — размеры, толщина линий, цвета, состояния hover/active. Сделать единый набор (векторный, на сетке), без эмодзи-символов вместо иконок.
2. Анимации как в AyuGram: посмотреть живьём (переходы чатов, выезд меню, окна, сообщения, реакции, кнопки, прокрутка, переключатели) и повторить длительности и кривые.
3. Эмодзи: настоящие эмодзи Telegram (как в AyuGram: стиль, размер), БОЛЬШЕ, как в Telegram (крупные одиночные эмодзи в сообщении, размер в панели, в тексте сообщений и в списке чатов, в поле ввода тоже картинками). Лицензию на Apple-набор учитывать: если распространять нельзя — использовать набор из самого AyuGram, который уже на диске у владельца, только локально, не коммитить в репозиторий (в .gitignore), или лучший открытый аналог, объяснив выбор.
4. Премиум-эмодзи (custom emoji): показ в тексте, в панели, статус Premium, отправка. В конце владелец зайдёт в Premium-аккаунт — вместе проверим живьём; до этого проверить всё, что можно, на обычном.
5. Ещё несколько этапов вперёд: анимированные стикеры (TGS/Lottie, WebM) с воспроизведением, панель GIF (сохранённые, поиск), «Мой профиль», «Новая группа», «Новый канал», звонки (хотя бы экран звонка, список, входящий/исходящий — оценить webrtc), «Настройки» Telegram (приватность, уведомления, данные, внешний вид, язык, устройства, папки чатов), альбомы и папки проверить вживую.
6. Убрать упоминания AyuGram в интерфейсе и названиях: везде заменить на «Rustgramm» (заголовки окон, «AyuGram Preferences» → «Rustgramm Preferences»/по-русски, раздел «AyuGram» в настройках, версия «AyuGram Desktop», подписи, логотип). В коде имена настроек можно оставить, но видимого «AyuGram» быть не должно.

ПРАВИЛА (из allskill и RRR.md): только Rust (Python — разовые скрипты в scratchpad); интерфейс на русском; чёрно-белая тема, цветные элементы редко и по делу; окно прозрачное 86% с регулятором; тесты на РЕАЛЬНОМ аккаунте в окне Rustgramm (после make-dist запускать dist\Rustgramm.exe, request_access `Rustgramm.exe`), тестовые сообщения писать ТОЛЬКО в чат sudoyp и потом удалять; пароли/коды не вводить; секреты не коммитить. После каждого этапа: clippy -D warnings, cargo test, bash scripts/make-dist.sh, живая проверка в окне, обновить RRR.md, поднять версию, git commit + push в main. Heredoc с кириллицей в Bash ломается — патчи писать файлами и запускать python.

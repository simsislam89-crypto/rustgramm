/allskill Продолжаем Rustgramm — порт AyuGram Desktop и Telegram Android на Rust (egui). Сначала прочитай RRR.md (разделы «Этап 26 (v0.15.0)», «Этап 27 (v0.16.0)», «Этап 28 (v0.17.0)») и docs/PARITY.md. Версия сейчас 0.17.0.

СУТЬ: интерфейс и поведение 1 в 1 как в настоящем AyuGram, с оранжевыми основными кнопками, непрозрачным стартом (100%) + регулируемой прозрачностью окна и кнопок с iOS/Acrylic-блюром. Эталон — запущенный D:\download WIN\AyuGram\AyuGram.exe.
Единственный релизный файл — `dist\Rustgramm.exe` (`scripts/make-dist.sh` обновляет его на месте, не создавая `-new`).
Утилита автотестов и сверки на рабочем столе — `vendor\rg-click\target\release\rg-click.exe` (команды `prep`, `side-by-side`, `click-win`, `hover-win`, `shot`, `crop`, `frames`, `diff`, `tour` автоматически сворачивают все окна кроме AyuGram и Rustgramm).

ЧТО ДЕЛАТЬ ДАЛЬШЕ:
1. Нативный медиа-стек для звонков (WebRTC/UDP-транспорт + захват камеры/динамика) и нативный Android AudioRecord/MediaPlayer JNI для воспроизведения/записи голосовых и звуков на телефоне.
2. Полноценный редактор медиа перед отправкой (кроп/поворот/рисование на фото, сжатие, подпись, спойлер, таймер самоуничтожения медиа).
3. Поддержка Telegram Stars, подарков (Star Gifts), платных реакций и бизнес-чатов (быстрые ответы, часы работы).
4. Импорт и редактор кастомных тем `.tdesktop-theme` / `.attheme` и кастомных паков иконок AyuGram.
5. Android-нативная интеграция: системный выбор файлов/галереи, WebView для Mini Apps внутри APK, фоновые push-уведомления и постоянный ключ подписи APK в GitHub Secrets.

/allskill Продолжаем Rustgramm — порт AyuGram Desktop на Rust (egui). Сначала прочитай RRR.md (разделы «Этап 15», «Этап 15б», «Этап 16») и docs/PARITY.md. Версия сейчас 0.9.0.

СУТЬ: интерфейс и поведение 1 в 1 как в настоящем AyuGram, но с оранжевыми основными кнопками, непрозрачным стартом (100%) + регулируемой прозрачностью окна и кнопок с iOS/Acrylic-блюром. Эталон — запущенный D:\download WIN\AyuGram\AyuGram.exe. Для визуальных сверок на рабочем столе есть утилита `vendor\rg-click\target\release\rg-click.exe` (или `request_access` в Claude Code).

ЧТО СДЕЛАНО В v0.9.0 (не переделывать, только проверять и улучшать):
- Непрозрачный старт (100%) + ползунок прозрачности (15–100%) масштабирует фоны, меню и ВСЕ кнопки (`t_btn`, `sync_visuals`), при < 100% включается системный Acrylic-блюр (`win::set_window_blur`).
- Оранжевые основные кнопки (`orange_button`), кнопка отправки, переключатели, ползунки, бейджи непрочитанных и прогресс-бар плеера.
- Анимации iOS (`ios_spring`, матовая вуаль, стеклянный блик, переливающийся скелетон при загрузке чата, каскадный blur-dissolve выход сообщений, плавное проявление картинок).
- Ускорение: дисковый кэш чатов и папок (`dialogs_cache.json` + предзагрузка аватарок), параллельный `tokio::join!` при старте, кэш истории в памяти, неблокирующие `Cmd::Open/Older/Search`, виртуализация списка чатов (`show_rows`), предбакетирование эмодзи.
- Потоковое видео (`stream.rs`, loopback `127.0.0.1` Range 206), автозапуск GIF в ленте (`InlineGifView`), поиск эмодзи (встроенный словарь + `messages.getEmojiKeywords`) и закрепление панели, создание/правка/удаление папок (`messages.updateDialogFilter`), стили фона чата, глобальный поиск (`contacts.search`), утилита `vendor/rg-click`.

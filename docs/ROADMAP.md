# Rustgramm — этапы порта AyuGram на Rust

Принципы: данные уходят только на серверы Telegram (`rg-net`), без телеметрии, значков, удалённой конфигурации и крэш-отчётов.
Всё прочее — по явному действию пользователя с показом хоста. Код — только Rust.

| Этап | Содержание | Состояние |
|---|---|---|
| 1. Основа | workspace, `rg-net` (страж хостов + CI-проверка исходников), `rg-settings` (режим призрака без телеметрии) | сделано |
| 2. Ядро MTProto | `rg-core`: подключение к DC Telegram через `grammers`, вход, сессия (шифрованная), обновления, прокси MTProxy/SOCKS5; все сокеты через `rg-net` | сделано (без живого входа) |
| 3. Функции AyuGram | `rg-ayu`: сохранение удалённых/изменённых сообщений (SQLite), режим призрака (перехват read/online/typing на уровне запросов), фильтры, запись правок, отправка без звука/по расписанию | сделано: политика призрака, хранилище, поток обновлений |
| 4. ПК-интерфейс | `rg-desktop` на egui: чаты, лента, ввод, медиа, настройки; один процесс, асинхронный tokio | первая версия: вход, чаты, сообщения, отправка, переключатели |
| 5. Медиа и звонки | загрузка/кэш, стикеры/Lottie, голосовые; звонки — по отдельной оценке | медиа сделано (фото, стикеры WebP, файлы, кэш 200 МБ); звонки отложены |
| 6. Android | `rg-android`: общее ядро + интерфейс на Rust (`android-activity`), сборка `cargo-ndk`, без Firebase/Google-сервисов | заготовка: rg-android + узкий режим UI; APK ждёт SDK/NDK |
| 7. Скорость | замеры «до/после» (запуск, память, прокрутка) против оригинала | |

Не переносим: Sentry, `update.ayugram.one`, `api.exteragram.app`, jsdelivr, dpaste, iTunes, Firebase, Python/Chaquopy, значки «разработчиков».

## Звонки (оценка, этап 5)
Звонки Telegram — это WebRTC-стек `tgcalls` (C++), сквозное шифрование и отдельные TL-запросы `phone.*`. Зрелой Rust-реализации нет;
порт потребует `webrtc-rs`, кодек Opus и сквозное шифрование по спецификации. Это отдельный большой этап после запуска текстового клиента и Android,
поэтому сейчас звонки не переносятся, а входящий вызов показывается как служебное сообщение.
